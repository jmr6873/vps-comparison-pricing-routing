# 搬瓦工 vs Linode：线路、价格和计费方式逐项对比，看完知道该选哪家买 VPS

搜“搬瓦工 vs Linode”的人，基本都卡在同一个岔路口：一边是传说中“国内访问快”的搬瓦工，一边是老牌正规军 Linode，价格差着好几倍，不知道这笔钱花得值不值。

这两家确实都是活了十年以上的老牌商家——搬瓦工（BandwagonHost）是加拿大 IT7 Networks 旗下的 VPS 品牌，2012 年创立，主打自助管理的 KVM VPS；Linode 资历更老，2003 年就开始做 VPS，后来被 Akamai 收购，现在官网叫 Akamai Cloud。但它们的定位早就分岔了：搬瓦工的核心卖点是针对中国大陆优化的 CN2 GIA 等线路；Linode 走的是标准公有云路线，按小时计费、机房多、配套服务全。

这篇文章把两家当前官网在售的价格、套餐、计费方式、线路质量和限制条件逐项摆出来，你对照自己的用途做选择就行。

## 先说结论

- **主要给国内用户访问**（网站、应用面向大陆用户）：基本没有悬念，选搬瓦工。Linode 没有 CN2 GIA 这类国内优化线路，也没有香港节点，有用户在 Reddit 上反映国内 ping 值偏高。
- **按时计费的短期项目、自动化测试**：选 Linode。它按小时计费，实例删掉就停止计费，搬瓦工便宜的套餐最少要年付。
- **预算极度敏感的长期项目**：搬瓦工年付 $49.99 起，同等开支在 Linode 只够买一个月 2GB 套餐，差距很大。
- **需要块存储、对象存储、Kubernetes、GPU 这类云配套**：Linode 有完整产品线，搬瓦工就是一台纯粹的 VPS。

## 两家现在分别是谁

**搬瓦工（BandwagonHost）**：母公司 IT7 Networks Inc. 注册在加拿大，2012 年推出品牌，机房主要分布在美国（洛杉矶、弗里蒙特、纽约等），官网还提供温哥华、阿姆斯特丹等位置。控制面板 KiwiVM 是自研的，开关机、重装系统、切换机房、管理 rDNS 都在面板里完成。它常被误解为“美国商家”，其实公司主体在加拿大，这个细节在处理退款和工单时你会感觉到差别——后文会讲。

**Linode**：2003 年成立的美国 VPS 先驱，被 Akamai 收购后品牌并入 Akamai Cloud，官网 Logo 也已经换成 Akamai。目前在全球有 24 个数据中心，覆盖四大洲，产品线从 $5/月的共享 CPU 小鸡一直到每月数千美元的 GPU 实例。

一句话概括定位差异：搬瓦工是“买一台长期用的 VPS”，Linode 是“租一段时间的云主机”。

## 线路质量：这是两家最本质的差别

搬瓦工的套餐名里那些 CN2、CN2 GIA-E 不是营销词，是实打实的路由方案：

- **CN2 GIA**：中国电信的精品回程网络，从美国机房回国的路由全程走电信 CN2 节点，晚高峰丢包和延迟明显好于普通线路。
- **CN2 GIA-E 系列**：洛杉矶 DC6/DC9 机房，2.5Gbps 带宽起步，除了 CN2 GIA，还可以自助切换到东京 JPOS_1、阿姆斯特丹 EUNL_9 等机房。
- **SLA 系列**：洛杉矶机房，官方页写明回程覆盖电信 CN2 GIA/CTGNet、联通 AS10099、移动 CMIN2，并直接对等连接 Apple、Google、ByteDance 等网络，附带 99.99% 的服务等级协议。
- **香港/大阪/东京系列**：香港是三网直连，大阪是三网回程 CN2 GIA。

Linode 的所有机房走的是普通 BGP 公网线路，没有任何针对中国大陆的优化，也没有香港数据中心。这不是“谁更快”的问题，而是产品定位问题：Linode 面向全球通用场景，不为某个国家的访客单独调路由。

第三方基准测试也能佐证基础性能的差别不大：VPSBenchmarks 对 Linode Shared 4GB 的实测里，网页性能 C、CPU E、性能稳定性 B、磁盘 IO D、网络 C，属于中规中矩的水平。两家在“纯算力”上都不是短板，真正拉开体验的就是从国内访问时的那段路由。

## 计费方式和隐性成本

这部分差异比跑分更影响钱包。

**计费周期**：Linode 按小时计费、按月封顶，实例删除即停止计费，特别适合跑几天就销毁的测试任务；但注意“关机”不等于“停计费”，保留数据的实例关着也照样收钱。搬瓦工的便宜套餐有最低付费周期：$49.99 的 KVM 和 CN2 特惠方案必须年付，$169.99 的 CN2 GIA-E 必须季付，只有更贵的档位才能月付。

**备份**：搬瓦工所有套餐自带免费自动备份和免费快照；Linode 备份从每月 $2 起，属于加购项。跑一年下来，这项差价在低价套餐上能到 40% 的总价差。

**换 IP**：Linode 的常规做法是销毁实例重建来换 IP，不额外收费。搬瓦工换 IP 一般要付 $8.79 一次，只有 SLA 系列提供每两周一次的免费 IP 更换。如果你的服务对 IP 封禁比较敏感，这笔开销要提前心里有数。

**流量超出**：Linode 超流量按 $0.005/GB 计费；搬瓦工套餐流量是固定的，超了则限速，不会产生额外账单。两种模式各有优劣，取决于你更喜欢“账单可预测”还是“超额弹性”。

**支付门槛**：搬瓦工支持支付宝、PayPal 和信用卡，国内用户购买很顺；Linode 账号需要绑定信用卡激活，对没有国际信用卡的用户是个硬门槛。

## 机房数量和配套服务

Linode 在这一点上有压倒性优势：24 个数据中心，配套有块存储（$1/10GB 起）、对象存储（$0.02/GB）、NodeBalancer 负载均衡、托管 Kubernetes，GPU 实例 $350/月起步。如果你的项目会逐步长成“一套小架构”，这些组件迟早用得上。另外 Linode 首页目前给符合条件的新用户最高 $5,000 的账户赠金活动，可以抵扣一部分成本。

搬瓦工的产品就是一台 VPS：KVM 虚拟化、一个 IPv4、一个 /64 的 IPv6 段、免费机房迁移、快照和备份，没有附加云产品。多机房免费切换是它的特色——同套餐在美国十几个机房和日本、欧洲节点之间自助迁移，这在使用上是实打实的灵活性。有评测也提到，Linode 对新开业务的审核和风控提醒比较频繁，跑敏感业务时收到的邮件通知会多一些。

## 稳定性、工单和售后条款

两家的在线率承诺：搬瓦工普通套餐 99.95%（官网套餐页写明，官网退款页另写 99.9% uptime guarantee），SLA 系列 99.99% 并有对应的补偿协议；Linode 没有公开的逐台 SLA 承诺，社区里对其稳定性评价历来不差。

工单响应是被吐槽最多的差别。搬瓦工客服只在加拿大当地工作时间处理，工单几小时到一天回复是常态；Linode 有全天候技术团队，响应快。对生产业务来说这个差别不小。

退款政策上，搬瓦工官网提供 30 天退款（需符合服务条款；根据第三方整理，还要求新账户、VPS 数量和累计支付金额在限定范围内、IP 未被封）；Linode 按用量扣费，本身不涉及“退款周期”的概念。搬瓦工 ToS 明确允许 VPN 和代理类用途，Linode 的条款同样不禁止这类应用，这点不用太纠结。

## 按人群给建议

- **个人博客、轻量建站、面向国内读者**：搬瓦工 KVM 或 CN2 特惠（$49.99/年）足够，预算宽一点直接 CN2 GIA-E。
- **外贸、电商、企业官网，要求国内访问稳定**：CN2 GIA-E 或 SLA 系列，后者有 99.99% 协议和每两周免费换 IP。
- **短期测试、CI 跑批、弹性伸缩**：Linode 按小时计费，用完即删。
- **面向全球用户、需要云配套**：Linode 的机房覆盖和产品线更合适。
- **既想省心又想省钱跑长期项目**：搬瓦工年付的总成本优势很难绕过去。

### 常见问题

**搬瓦工和 Linode 哪个速度更快？** 取决于访客在哪。国内电信用户访问搬瓦工 CN2 GIA 系列通常明显更快；海外访客访问两家差别不大。

**Linode 现在还叫 Linode 吗？** 品牌已并入 Akamai Cloud，官网和登录入口都换成 Akamai 的了，服务本身照常运行。

**搬瓦工最便宜的套餐多少钱？** 常规在售最低是年付 $49.99 的 KVM/CN2 特惠套餐（1GB 内存、1TB 月流量）；不定期上线的限量套餐曾低到 $19/年，但基本靠抢。

**两家能互相迁移吗？** 没有一键迁移工具，靠快照加重装自己搬。搬瓦工免费快照功能在这个场景很好用。
